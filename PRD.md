**📘 PRODUCT REQUIREMENTS DOCUMENT (PRD)**

**🏫 Product Name: _GLOBAL AUTISM Learning School Management System_**

**1\. 🎯 Product Overview**

A **web-based school management system** designed specifically for **GLOBAL AUTISM LEARNING SCHOOL**, supporting:

- School Administration
- Teachers / Educators
- Parents

The platform will streamline **academic management, therapy tracking, communication, and reporting**, especially tailored for children with autism.

**2\. 👥 User Roles & Panels**

**1\. 🛠️ Admin Panel (School Management)**

**2\. 👩‍🏫 Teacher Panel (Educators / Therapists)**

**3\. 👨‍👩‍👧 Parent Panel**

Each role has **separate login + dashboard + permissions**

**3\. 🔐 Authentication & Access**

- Role-based login system
- Email + Password / Mobile OTP login
- Admin can:
  - Create / Edit / Delete users
  - Assign roles (Teacher, Therapist, Parent)
- Multi-device support (Web + Mobile responsive)

**4\. 🛠️ ADMIN PANEL FEATURES**

**🏫 4.1 School Setup**

- Create Classes (e.g., Autism Level 1, Level 2)
- Create Sections (A, B, C)
- Assign Class Teachers
- Assign Subjects / Therapies

**📅 4.2 Timetable / Period Management (IMPORTANT FEATURE)**

- Create **Class Period Structure**
  - Example:
    - Period 1 → Speech Therapy
    - Period 2 → Occupational Therapy
    - Period 3 → Sensory Integration
- Teachers can:
  - **Edit Period Names (FREE EDIT FEATURE)**
  - Customize per class/section
- Drag & Drop timetable system

**👨‍🏫 4.3 Staff Management**

- Add Teachers / Therapists
- Assign:
  - Classes
  - Subjects
  - Therapy Roles
- Track attendance of staff

**👨‍👩‍👧 4.4 Student Management**

- Add Student Profile:
  - Name, Age, Diagnosis, Parent Details
- Upload documents:
  - Medical reports
  - Assessment reports

**📊 4.5 Reports & Analytics**

- Attendance Reports
- Therapy Progress Reports
- Class-wise performance
- Export as PDF

**💰 4.6 Fees Management**

- Fee structure creation
- Payment tracking
- Online payment integration
- Discounts / Promo Codes (e.g., JOINMAY 25%)

**🍽️ 4.7 Diet & Nutrition Module (Your requirement)**

- Assign:
  - Specialized food plans
  - Detox water schedules
- Dietician access to update plans

**📢 4.8 Communication System**

- Announcements
- SMS / Email / App notifications
- Broadcast to:
  - All parents
  - Specific class

**5\. 👩‍🏫 TEACHER PANEL FEATURES**

**📊 5.1 Dashboard**

  - Text notes

- Fields:

**👶 5.4 Student Tracking**

**📊 5.5 Assessment Tools**

- Progress graphs

**📷 5.6 Media Upload**

**📩 5.7 Communication**
